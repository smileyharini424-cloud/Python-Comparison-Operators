# Python Comparison Operators

## Explanation

This program demonstrates comparison operators in Python. Comparison operators are used to compare two values and return either `True` or `False`.

## Problem Statement

Write a Python program that accepts two numbers from the user and demonstrates different comparison operators.

## Features

* Accepts two numbers as input
* Compares the two numbers
* Demonstrates six comparison operators
* Displays `True` or `False` as the result

## How It Works

The program takes two integer values from the user and applies:

* `==` Equal to
* `!=` Not equal to
* `>` Greater than
* `<` Less than
* `>=` Greater than or equal to
* `<=` Less than or equal to

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Read the first number.
3. Read the second number.
4. Apply comparison operators.
5. Display the results.
6. End the program.

## Sample Input

```text
Enter first number: 10
Enter second number: 20
```

## Sample Output

```text
Equal: False
Not Equal: True
Greater Than: False
Less Than: True
Greater Than or Equal: False
Less Than or Equal: True
```
